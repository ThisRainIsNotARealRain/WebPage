约稿 / 合作 我们的愿景

愿景

让每一个被爱的角色，都能在更多介质里活下去

追番、抽卡、买谷、刷二创——我们和你一样，相信「喜欢」值得被认真对待。角色不该只活在一张立绘或一季番剧里；好的世界观，理应在 PV、短叙事、活动视觉、联名物料里一次次被擦亮，被更多人接住。

非雨的愿景，是成为最懂二次元语境的内容出品方之一：用工业级的稳定产能托住商业交付，用创作者式的洁癖守住审美与「对味」。我们希望，当你把 IP 交给我们做衍生时，感受到的不是冷冰冰的外包，而是同好之间的靠谱与热血。

往远看，我们要让自有平台与 in-house 产能持续喂养自己的内容资产与 IP 矩阵——从承制走向共创，从单次项目走向长线运营，让好故事有机会在更多平台、更多形态里自然生长。

  • 对味优先：再快的产能，也不能牺牲「这很二次元」的直觉。
  • 交付可信：档期与品质说到做到，让合作方敢把 S 级 IP 交过来。
  • 资产思维：每一次制作，都为下一次更省、更好、更敢想铺路。
  • 同好精神：我们招内容、聊合作，先看懂不懂番、爱不爱角色。

公司

二次元内容公司，不是「顺便做做动画」的乙方

市场要的是高频、多形态、会玩梗还会破圈的视觉内容；传统作坊接不住体量，纯工具又接不住审美与叙事。非雨选择站在内容与 IP这一侧：我们自建面向二次元赛道的生产平台，把流程、素材与审美标准握在自己手里，再用 in-house 团队成片，专门啃难而美的衍生与定制。

简单说：我们既做出品，也做能支撑出品的那套家当——为的是让每一次「想给角色多做一点」的野心，都找得到落点。

商业模式

平台托底 · In-house 出品 · IP 衍生承制为核心

当前阶段，我们以商业定制与 IP 衍生内容制作为主要收入与练兵场：为平台方、文旅与品牌客户、持有版权的 IP 方提供从策划到成片的系列交付。每一笔订单，都会在自有平台上沉淀可复用的风格、模板与制作经验，让下一轮更快、更稳、更敢接难题。

自有生产平台

面向二次元内容场景搭建的内部平台，把高频物料、多版本适配和跨部门协作「铺平成路」——让产能跟得上脑洞，让品控跟得上热爱。

In-house 主控成片

核心导演、美术与制作力量在公司体内闭环，审美口径统一、改稿链路短。你对接的是懂梗、懂镜头语言的「自己人」，而不是层层转包的黑箱。

IP 衍生与定制

番外短片、角色 PV、活动主视觉、系列社交物料、游戏 / 漫展向包装……我们擅长把已有 IP「翻译」成不同形态的内容实体，也欢迎长期框架约与联合企划。
