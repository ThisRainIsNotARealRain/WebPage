01 / 实体出版

消费品，是新的出版媒介

传统出版把作品印成书；非雨出版 IP，用的是消费品。角色与作品在授权范围内开发成周边与品牌商品，经生产与发行到达消费者手中。

01 · IP 方

设定与权利

角色、世界观、作品与素材，连同可授权范围和收益规则一起记录在案。

02 · 创作者 · 品牌方

授权开发

在授权范围内围绕设定与素材开发内容和商品，每一件衍生作品都有清晰记录。

03 · 生产方

生产履约

生产方按品类、工艺与交付能力接入，通过 OEM 批量生产或 POD 按需生产完成交付。

04 · 消费者

市集发行

商品在交汇地市集展示与发行，消费者的购买与反馈用来调整下一批商品方向。

开放创作，治理商业化

创作者可以用不同的工具、在不同的社区里创作；作品进入商业化时，使用范围、审核责任与收益规则都要先明确。

02 / 交汇地 CROSSROADS · 1.0

交汇地，IP 的开发与发行平台

交汇地是非雨运营的线上平台。IP 方在这里建立和经营 IP，创作者在授权范围内开发内容与周边，商品在平台市集展示与发行。

01 · IP 空间

为每个 IP 集中管理角色、世界观、素材与作品，版本与发布状态都可查。

02 · 授权共创

设定与素材连同创作许可按版本发布，创作者获授开发，作品保留来源与署名。

03 · 工房

围绕 IP 素材加工衍生内容，在线排版设计徽章、透卡与立牌等实体周边。

04 · 市集

周边商品在平台市集集中展示与发行，消费者从角色与作品直接找到商品。

03 / 合作方式

与非雨合作，开展 IP 商业化

具体授权与履约范围，根据项目约定。

业务方向 面向伙伴 合作内容
01

原创 IP 发行

面向伙伴原创作者

合作内容原创作者可将角色与作品交由非雨发行。非雨组织商品开发、生产与发行，权利与收益按约定划分。

02

标准品周边托管

面向伙伴IP 方

合作内容通过交汇地市集托管标准品周边，由平台组织商品展示、发行与生产协作，并结合购买与反馈调整后续商品方向。

03

授权共创

面向伙伴创作者

合作内容在授权范围内围绕 IP 的设定与素材开发内容及商品。平台记录作品与衍生关系，明确商业使用与收益规则。

04

品牌授权

面向伙伴品牌方

合作内容围绕自身受众、品类与渠道与 IP 方开展品牌授权合作，把角色与作品引入品牌商品并协同后续发行。

05

生产合作

面向伙伴生产方

合作内容按品类、工艺与交付能力接入非雨，通过 OEM 批量生产或 POD 按需生产，为平台商品发行提供生产与履约支持。
