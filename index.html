非雨是面向开放创作的 IP 商业化发行平台。我们以消费品为出版媒介，让角色与作品经过授权、开发与生产，成为可以买到的商品；IP 方、创作者与消费者，在这里连成一张发行网络。

How IP gets published

消费品，是新的出版媒介。

传统出版把作品印成书。非雨出版 IP，用的是消费品：角色与作品在授权范围内被开发成周边和品牌商品，经过生产与发行，到达消费者手里。

  1. 01IP 方

    设定与权利

    角色、世界观、作品与素材，连同可以授权的范围和收益规则，一起记录在案。

    RainOntology · RainHub

  2. 02创作者 · 品牌方

    授权开发

    在授权范围内，围绕设定与素材开发内容和商品。每一件作品的衍生关系都有记录。

    RainStudio

  3. 03生产方

    生产

    生产方按品类、工艺与交付能力接入，通过 OEM 生产或 POD 按需生产完成履约。

    OEM · POD

  4. 04消费者

    发行

    商品在 RainFair 展示与发行。消费者的购买与反馈，用来调整下一批商品的方向。

    RainFair

开放创作，治理商业化。

AI 扩大了 IP 的开发空间，也让权利关系更加复杂。创作者可以用不同的工具、在不同的社区里创作；作品进入商业化时，使用范围、审核责任与收益规则都要先明确。

  • 商品发行IP 方

    让角色与作品成为可购买的商品

    IP 方可以通过 RainFair 托管标准品周边，由平台组织商品展示、发行与生产协作，并结合消费者的购买与反馈调整商品方向。

  • 授权共创创作者

    参与 IP 开发，让作品进入商业化

    创作者可以在授权范围内，围绕 IP 的设定与素材开发内容及商品。平台记录作品与衍生关系，明确商业使用与收益规则。

  • 品牌授权品牌方

    将 IP 引入品牌商品，拓展更多消费品类

    品牌方可以围绕自身的受众、品类与渠道，与 IP 方开展品牌授权合作，把角色与作品用于商品，并协同后续发行。

  • 生产合作生产方

    成为非雨的标准供应商

    生产方可以按品类、工艺与交付能力接入非雨，通过 OEM 生产或 POD 按需生产，为平台的商品发行提供生产与履约支持。
