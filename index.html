愿景

让 IP 在更多渠道里，有稳定、好执行的内容出口

角色和世界观被投入市场之后，往往要面对短视频、直播、线下活动、联名物料等一连串露出。我们希望在「要做得像那么回事」和「要按档期交片」之间，给客户一个靠得住的选项。

公司会持续投入自有制作能力与内部平台，先把商业委托做扎实；在此基础上，再逐步探索自有内容与长期 IP 运营。对合作方，我们看重沟通是否直接、修改是否可追溯、成稿是否可复用到下一波传播。

  • 内容和广告都讲审美，我们按成片说话，少堆概念。
  • 档期与规格在合同与排期里写清楚，执行过程尽量透明。
  • 同一 IP 多批次合作时，风格与素材能接续，而不是从零打散。
  • 团队对二次元商业内容有日常接触，沟通成本相对低。

公司

我们是谁

非雨文化科技是一家面向企业及版权方的内容供应商，主营业务是二次元风格的视频与相关视觉物料。公司不设层层外包的「壳」，核心制作与项目管理以 in-house 为主，需要外部支援时在项目层面单独约定。

内部有一套自用的生产协同环境，用来管版本、排期与交付物归档。对客户而言，这体现在：对接人相对固定、改稿路径短、同一项目里的资产不容易丢。

业务与模式

三件事

当前收入以项目制委托为主：按合同约定交付成片与约定格式的源文件。以下为常设能力划分，便于询价时对照。

内部制作平台

自用流程与资产管理，不单独对外售卖。作用是支撑多环节并行、版本可查，减少「文件在谁手里」这类沟通损耗。

自有制作团队

导演、美术与后期等核心岗位在公司编制内。客户通常与制片或导演直接对齐脚本与画面，避免需求在中介环节失真。

IP 衍生与定制

承接已有版权素材基础上的二次创作与包装，例如角色短片、纪念影像、展陈与社交传播物料。具体权利范围以合同与版权方授权为准。
