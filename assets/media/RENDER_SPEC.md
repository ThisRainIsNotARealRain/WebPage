# 连续性大图 重出规格（continuity-board-cel-v2）

这张图是官网最重要的一张，全站的论点靠它成立：**同一个角色，从草图一路走到摆件，中间没有走样。**它现在的问题是整张画都是厚涂，跟 `DESIGN.md` 里「禁止厚涂、颗粒、纸张纹理和噪点覆盖」这条自己定的规矩冲突，而且左右两半没有材质区分，看不出「从画走到实物」这件事。

重出的时候左右两半要分开处理。

## 画面结构（保持不变）

从左到右五段，顺序不要改，这个顺序对应站上的五个阶段标签：

| 段 | 内容 | 站上标签 |
| --- | --- | --- |
| 1 | 铅笔草图：角色两个视角 + 淡蓝构图辅助线 + 场景透视线稿 | 设定 Design |
| 2 | 四格竖排分镜，灰调，角色在场景里由远及近 | 分镜 Storyboard |
| 3–4 | 两幅完成画面：雨中回廊俯瞰海面 / 晴天崖边石板路 | 成片 Frame |
| 5 上 | 墙上挂着的卷轴印刷品，单色，同一场景 | 印刷 Print |
| 5 下 | 木台面上的角色摆件，带圆形底座 | 实体 Object |

角色一致性是这张图的全部意义：**红发、深灰破边长袍、右手一把长杖／长剑，五段里必须完全一致**。任何一段对不上，这张图就白做了。

## 左边（第 1–4 段）：改成赛璐璐

- **平涂**。每个色块两到三个色阶封顶：固有色 + 一层阴影，最多再加一个高光。不要渐变堆叠，不要笔触感。
- **线稿清晰可见**。角色和前景建筑保留干净的描线，线宽有粗细变化但不要毛边。
- **阴影是硬边的**，形状明确，不做柔化过渡。
- **细节减量**。远景的城市、山、海浪都简化成剪影和色块，不要一片片刻画屋瓦和浪花。现在这版远景信息量太满，眼睛没有落点。
- **底色留白**。第 1 段草图那块保持接近纸白的浅底，让整张图从左到右有一个「越来越实」的过渡。
- 参照的是赛璐璐动画的美术设定稿和背景板，不是插画。

## 右边（第 5 段）：改成真实 3D 质感

- 挂轴和摆件要读起来是**照片里的实物**，不是画出来的实物。这是整张图的落点：世界最后变成了桌上的东西。
- 摆件：树脂／PVC 手办的材质感。表面有轻微不均匀的高光，衣褶边缘有一点次表面透光，底座是磨砂黑或者哑光金属，带清楚的接触阴影和一点点环境反射。
- 挂轴：纸或者绢的纤维质感，边缘有实体厚度，画面本身仍是单色印刷。
- 光源和木台面反射要跟摆件对得上，摆件要真的「站在」台面上。
- 左右两半的分界可以是那道竖直的墙沿，从赛璐璐平涂过渡到实拍质感，过渡要干脆，不要中间调和。

## 验收

把新图放大到 2048 宽，逐条对：

1. 五段里的角色是同一个人吗？发色、袍子破边、武器都对得上吗？
2. 左边有没有任何一处还是厚涂或者有噪点／纸纹？
3. 远景的信息量是不是明显比现在少？
4. 右边的摆件，第一眼像照片还是像画？
5. 从左到右扫一遍，能不能看出「草图 → 分镜 → 成片 → 印刷 → 实物」这条线？
